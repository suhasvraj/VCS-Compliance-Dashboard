# Vishaal Consultancy Services (VCS) – Compliance Management Dashboard

> **Project Status: Demo Version / Prototype**

## 📌 Project Overview

The **VCS Compliance Management Dashboard** is a consultancy-based web application prototype designed to streamline compliance management and improve coordination between consultancy staff and their clients.

The platform provides a centralized interface for managing client information, tracking compliance documents, monitoring file submissions, and keeping track of important statutory deadlines and compliance-related activities.

The primary objective is to simplify document management, improve transparency, and ensure better coordination between the consultancy and its clients.

**Note:** This is a demo version developed to demonstrate the proposed system's user interface, features, and workflow. It is not the final production-ready application.

## 🚀 Key Features

### 1. Staff Dashboard
- Staff overview and dashboard analytics.
- Client management and client categorization.
- Task tracking and management.
- Document upload tracking.
- Compliance progress monitoring.
- Deadline calendar and reminders.
- Reports and analytics sections.

### 2. Client Portal
- Dedicated client dashboard.
- Compliance document management.
- Document submission tracking.
- Compliance completion percentage.
- Upcoming deadline visibility.
- Monthly, quarterly, half-yearly, and annual compliance tracking.

### 3. Document Management
- Track compliance documents.
- Monitor uploaded and pending documents.
- Document status indicators.
- Document-related remarks and feedback.
- Simulated document upload and download workflows.

### 4. Deadline Management
- Compliance deadline calendar.
- Upcoming and overdue deadline indicators.
- Reminder management.
- Monthly and periodic compliance tracking.

### 5. User Interface
- Staff and client interfaces.
- Responsive dashboard layout.
- Light and dark mode.
- Search functionality.
- Notifications panel.
- Interactive analytics and progress indicators.

## 💻 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure the required assets, including the VCS logo, are present.
4. Open the `index.html` file using the Live Server extension.
5. Access the dashboard through your browser.

## ⚠️ Demo Version – Important Notes

This repository contains a prototype/demo implementation of the VCS Compliance Management Dashboard.

- Demo data is stored locally using browser LocalStorage.
- Certain document upload and download operations are simulated.
- The current version is intended for demonstration and evaluation purposes.
- It is not connected to a production database or live company server.
- Authentication and data handling are not production-grade security implementations.

Further development and backend integration are required before production deployment.
